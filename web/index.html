MemoryATHENA: Adaptive Routing over Latent and Generated Memories

A reader-first memory interface that keeps direct Engram retrieval as a stable anchor and admits generated memory only when the router predicts that it will help.

AuthorsOLA Research
VenuePreprint
DateSeptember 2026
MMemory systems · OLA Research

Abstract

External memory is useful, but a generated memory representation is not uniformly better than direct retrieval. MemoryATHENA separates memory storage from memory selection: it freezes the Engram memory and reader pathways, then trains a lightweight router from causal-text counterfactual advantages relative to E.

At inference time, the router can modify the direct path through bounded interpolation. If a generated candidate is not useful or confident enough, the system falls back exactly to E. This gives the model a stable memory reference while still allowing target-side generated proposals to help on inputs where they are better aligned.

Methods

Three pathways, one reference

MemoryATHENA turns one retrieved memory value into complementary reader views, then learns a compact E-relative decision rule over those views.

E

Direct Engram retrieval

The stable reference pathway. Retrieved memory is projected into the target backbone without requiring a generated candidate.

GE

Generated from Engram cues

A generator conditions on retrieved Engram representations to produce a target-side memory proposal.

GH

Generated from backbone states

A generator conditions on clean causal hidden states, providing a complementary proposal that does not directly consult the memory table.

  • AddressingStable memory lookup

    The Engram memory remains frozen and addressable, preserving a shared external artifact across target-side reader experiments.

  • ReadersTarget-aligned interfaces

    Direct, Engram-conditioned, and hidden-state-conditioned readers expose complementary memory views to the target backbone.

  • RouterCounterfactual supervision

    The router is trained from future-token likelihood advantages of GE and GH relative to E, not from downstream task labels.

Bounded admission + exact fallback.

A proposal is admitted only when its predicted advantage and confidence pass the configured rule; otherwise inference returns exactly to the direct E reference.

Research questions

What does adaptive memory selection test?

  • RQ1Portability

    Can a frozen memory remain useful across target backbones, tokenizers, and task families?

  • RQ2Reader design

    How do direct and generated-memory interfaces change what the target model can extract?

  • RQ3Selective use

    When should generated memory modify, rather than replace, direct retrieval?

Key findings

What the experiments show

  • 1. Generated memory is useful, not universal

    GE and GH can complement direct retrieval, but neither uniformly dominates E. The router keeps the strong path available on inputs where generation would interfere.

  • 2. The reader is part of the transfer

    A frozen memory becomes useful on a new backbone through a target-side reader aligned to that backbone, rather than through the table alone.

  • 3. Selective routing is the central mechanism

    The gains come from bounded intervention around a strong direct-memory reference, with exact fallback when generated proposals are not sufficiently useful.

  • 4. Results need their caveats

    Vanilla NLP uses a historical scorer, and the Yahoo threshold is shown explicitly. The release keeps both facts visible so the headline averages remain auditable.
